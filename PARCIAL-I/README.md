## Descripción del programa
Proyecto Java que emula un entorno interactivo de cajero automático. Maneja control de acceso por contraseña, revisión de saldo, abonos de efectivo, retiros simples y con recargo utilizando sobrecarga de métodos, finalizando con un resumen detallado de la actividad realizada.
