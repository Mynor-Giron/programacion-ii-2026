## 📌 Descripción de la Aplicación
Esta solución integra el diseño conceptual de una API REST junto con una aplicación de consola desarrollada en Java para la administración eficiente de pendientes personales. La herramienta habilita la clasificación de actividades según su nivel de prioridad y facilita el monitoreo continuo sobre el estado de avance o finalización de cada registro.

## 🚀 Stack Tecnológico
* **Lenguaje:** Java 17 (o versión superior)
* **Gestor de proyectos:** Apache Maven
* **Intercambio de datos:** JSON (estructuración y formato)
* **Arquitectura de red:** REST / Protocolo HTTP (diseño de endpoints)

## 📦 Configuración del Proyecto Maven

* **version:** `1.0-SNAPSHOT`

### Glosario de Parámetros Maven
* **groupId:** Corresponde al identificador de la organización o paquete raíz del desarrollo (siguiendo la estructura de dominio invertido).
* **artifactId:** Representa la denominación individual del módulo o del artefacto ejecutable resultante.
* **version:** Especifica la etapa actual del ciclo de vida del software (el distintivo `SNAPSHOT` indica un estado activo de construcción).
