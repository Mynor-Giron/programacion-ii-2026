## Sistema de Figuras Geométricas

## Breve Descripción

Este proyecto consiste en un programa desarrollado para trabajar con diferentes figuras geométricas. El sistema permite crear y manejar las figuras implementadas, aplicando los principios de la programación orientada a objetos.

## Figuras Implementadas

Las figuras implementadas en el programa son:

Círculo
Rectángulo
Triángulo

## Instrucciones para Ejecutar el Programa
Abrir el proyecto en un entorno de desarrollo compatible con Java.
Verificar que todos los archivos del proyecto se encuentren correctamente organizados.
Compilar las clases del programa.
Ejecutar la clase principal que contiene el método main.
Seguir las instrucciones que aparecerán en pantalla para utilizar el programa.
