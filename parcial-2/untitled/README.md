# Sistema de Gestión de Estacionamiento

## Descripción

Programa desarrollado en Java para gestionar un estacionamiento. Permite registrar vehículos, buscar por placa, mostrar información y calcular los costos y la recaudación.

## Funciones

* Registrar automóviles y motocicletas.
* Evitar placas repetidas.
* Mostrar y buscar vehículos.
* Calcular el mayor costo.
* Mostrar la recaudación total y por tipo.

## Conceptos utilizados

* Programación Orientada a Objetos.
* Herencia y polimorfismo.
* Encapsulamiento.
* `ArrayList`, `HashSet` y `HashMap`.
* Manejo de excepciones.

## Ejecución

1. Abrir el proyecto en NetBeans, IntelliJ IDEA o Eclipse.
2. Ejecutar `Main.java`.
3. Seleccionar una opción del menú y seguir las instrucciones.
