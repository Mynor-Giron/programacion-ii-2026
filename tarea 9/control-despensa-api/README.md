# 🏠🥫 API REST - Despensa del Hogar

**Estudiante:** Mynor Adolfo Girón Muralles
**Carnet:** 9941-25-8300

API REST básica con **Spring Boot** para consultar y analizar los productos
de la despensa de un hogar. Los datos se mantienen **en memoria** (sin JPA
ni operaciones POST/PUT/DELETE).

---

## 🛠️ Tecnologías

| Herramienta | Versión |
|---|---|
| Java | 17 o 21 |
| Spring Boot | 3.3.x |
| Maven | 3.9+ |
| Spring Web | Starter |
| Jackson | Incluido |
